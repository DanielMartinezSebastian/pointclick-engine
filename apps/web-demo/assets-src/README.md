# Fuentes de arte (no se sirven)

Material de terceros descargado tal cual, para elegir de aquí los assets de la demo con historia (Fase 18). Esta carpeta **no** está bajo `public/`: no se sirve ni se despliega. Lo que se use en el juego se copia a `public/assets/` y se anota en el `LICENSES.md` de arte correspondiente.

## Convenciones

- Los archivos se guardan sin modificar, con su nombre original.
- Los iconos se escalan ×2 sin suavizado al copiarlos a `public/assets/`, para igualar los 64×64 de los ítems actuales.
- Antes de añadir otro pack, comprobar su licencia y anotarla aquí. El repositorio es público: solo material que permita redistribución.
